Resumo curto: o datalock Studio não coleta nem envia os seus dados para lugar nenhum, por padrão — tanto na prévia web quanto no software completo. Esta página detalha exatamente o que isso significa.

Esta política descreve como o datalock Studio ("o software", "nós") trata dados ao ser usado — tanto na versão que roda no navegador ("prévia web") quanto na versão instalável ("software completo", incluindo a distribuída pela Microsoft Store).

1. Quem trata os dados, e onde

[SEU NOME OU EMPRESA] é quem desenvolve e distribui o datalock Studio. O software é uma ferramenta de uso local — os arquivos que você importa, transforma e anonimiza são processados inteiramente no seu próprio computador ou navegador. Nós (desenvolvedores) não temos acesso a esses dados, porque eles nunca chegam até nós: não existe um servidor nosso recebendo ou armazenando o que você processa no software.

Isso vale igualmente para a versão instalada pela Microsoft Store, pelo .exe direto, ou usada como prévia web.

2. Quais dados o software manipula

  • Arquivos que você importa (CSV, Excel, JSON, Parquet, .dlk): ficam em memória enquanto o programa está aberto, e só são gravados em disco quando você explicitamente exporta um resultado ou usa uma automação configurada por você mesmo.
  • Bancos de dados (só no software completo): se você configurar uma conexão, o software se conecta diretamente ao banco que você informou — nenhuma credencial ou dado passa por nós no meio do caminho.
  • Preferências de interface (tema, cor, densidade): salvas localmente no seu navegador/computador (localStorage), nunca enviadas para fora. Não são dados pessoais — só configurações visuais.
  • Segredos de anonimização (salt, chave de criptografia): digitados por você e usados apenas em memória durante o processamento. Nas automações (software completo), esses segredos podem ficar guardados localmente num arquivo de configuração (secrets.env) que você cria e controla — nunca são transmitidos para nós ou para terceiros.

3. O que o software NÃO faz

  • Não coleta estatísticas de uso, telemetria ou analytics.
  • Não envia os dados que você processa (ou qualquer parte deles) para nenhum servidor nosso ou de terceiros.
  • Não usa cookies de rastreamento.
  • Não compartilha, vende ou monetiza dados de qualquer tipo, porque não os recebemos.

4. Conexões de rede que o software faz

Software completo (instalado / Microsoft Store): por padrão, nenhuma. O programa roda um servidor local (127.0.0.1, acessível só pela sua própria máquina) e não faz nenhuma chamada de rede para fora, a menos que você mesmo configure uma conexão com banco de dados remoto ou uma automação cuja origem/destino seja remota — nesses casos, a conexão é feita diretamente do seu computador para o destino configurado, nunca passando por nós.

Prévia web: por rodar num navegador, a prévia carrega algumas bibliotecas de terceiros por CDN, necessárias para funcionar:

Essas requisições expõem ao provedor (Google/Cloudflare) informações técnicas padrão de qualquer requisição web (como seu endereço IP) — o mesmo que aconteceria em praticamente qualquer site que usa fontes ou bibliotecas hospedadas externamente. Os dados que você importa e processa dentro da prévia não são enviados a esses serviços — só os arquivos estáticos da própria interface são carregados de lá.

5. Anonimização e segurança dos dados

O propósito central do software é justamente proteger dados pessoais — as funções de mascaramento, criptografia e detecção de PII existem para isso. Detalhes técnicos de como cada método funciona estão documentados no Manual de Uso e Metodologia do projeto.

6. Retenção de dados

Não aplicável da nossa parte — como não recebemos nem armazenamos seus dados, não há nada para retermos ou apagarmos. A retenção dos arquivos que você processa é inteiramente controlada por você, no seu próprio computador.

7. Direitos do titular dos dados (LGPD/GDPR)

Como o software não processa dados pessoais em nome de terceiros nem os centraliza em nenhum sistema nosso, a maioria dos direitos previstos na LGPD (Lei 13.709/2018) e no GDPR — acesso, correção, exclusão, portabilidade — não se aplicam a nós como operadores, porque nunca chegamos a deter esses dados. Se você usa o software para tratar dados pessoais de terceiros (ex.: uma base de clientes da sua empresa), você é o controlador desses dados para efeitos legais, e as obrigações da LGPD/GDPR recaem sobre sua organização, não sobre o desenvolvedor deste software.

8. Crianças

O software não é direcionado a menores de idade e não coleta intencionalmente dados de crianças.

9. Alterações a esta política

Esta política pode ser atualizada eventualmente — a data no topo desta página indica a versão mais recente. Mudanças significativas serão refletidas na ficha do software na Microsoft Store (ou onde estiver distribuído) antes de entrarem em vigor.
